How it works

The hidden state is the car’s position. Each second it can stay or move to a neighboring street position, with equal probability for every available option. There are 93 possible positions; the initial position is uniform.

Switch to Model to see the same street positions as nodes. Every street edge has an arrow in each direction, and every state has a waiting loop. Select a node to see its outgoing probabilities; these depend on the number of choices at the source state. Select the same node again to clear its highlight.

In the chain view, the blue path starts with probability 1/93. Its transition labels use the number of choices at the source, including waiting; powers count repeated transitions. Each faint connector pairs the GPS observation at time t with the blue estimate at that same time. Its label is e−a², with a = d/(σ√2), where d is the distance from the unshifted model state to that GPS observation. Multiplying these factors gives the path's relative joint weight, not a normalized posterior probability. The Gaussian density factor 1/(2πσ²) per observation is common to every candidate path and is omitted from the labels.

Hover over an orange GPS point or a blue path point to highlight its same-time counterpart and connector. When the blue path visits the same displayed point more than once, hovering it highlights all corresponding observations. Hidden layers stay hidden.

GPS adds independent Gaussian noise to both coordinates, with standard deviation σ. Changing the slider preserves the route and scales the same noise. The map fits all GPS points at the chosen noise level and stays still as you step through the trip.

Viterbi finds the most probable complete path using only observations up to the selected time. A new observation can change earlier estimates. The model knows the roads, but not the car’s route or stops.

To separate overlapping paths, the true route is drawn slightly to the right of travel and Viterbi farther to the left. These offsets only affect the drawing; model states and GPS coordinates stay the same.
